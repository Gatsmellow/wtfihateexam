DeepSeek 能不能直接在浏览器里调用？

这个页面只做一件事：用你的 key 发一个带 Authorization 头的 GET 请求，看看浏览器是否被 CORS 拦截。它不会保存 key，也不会写入任何数据。

    怎么做
    1. 在 Chrome / Edge 里直接双击打开这个文件，或用本地服务器打开。
    2. 填入你自己的 DeepSeek key，点“发起跨域请求”。
    3. 看到 200 且下方列出模型，才算通过。若浏览器报 TypeError: Failed to fetch 或 CORS 错误，就是被拦截，需要停下来换方案。
    隐私：key 只在当前页面的内存中使用；请求直接发往你填写的 API 地址，不经过本站的任何服务器。页面没有埋点、没有日志上报。
